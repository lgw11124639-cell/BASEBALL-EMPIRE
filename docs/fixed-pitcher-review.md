# Fixed-proportion pitcher review

Entry: broadcast-fixed.html. The game entry, actor module, saves, and version
remain unchanged. The review is an explicitly separate 3D interpretation of
previous photographic references, not an assertion of identical photo quality.

Four deliveries each expose 120 deterministic poses at a 60Hz time base over
2 seconds. Frame controls allow inspection of any pose. Thirty-eight uniforms
share the same skin, proportions, and animation. RHP lifts the left leg from
close feet and keeps the right support sole fixed before stride. LHP mirrors
the same anatomical sequence. The same camera projects the catcher target and
ball flight; distance makes the ball shrink naturally.

The torso and limbs share welded mesh topology. No floating sleeve/hip patches.
Hand curves use measured anatomical reach. Bone scale is never animated.
Hair conforms to the actual skull. Cloth piping is skinned along the trousers.

Rebuild with Blender 4.3: blender --background --python scripts/build-fixed-pitcher.py.
The build output directory can be overridden with PITCHER_FIXED_OUT.
Validation scripts and JSON evidence accompany this review.
