# 2.0.53 선수 행동·프로필·중계 수정

공인구는 기준 3종을 돌아가며 선택하지 않는다. 완주한 두 시즌에서 타율·ERA·팀당 득점·홈런 중 둘 이상이 같은 방향으로 벗어나면 현재 수치에서 조정안을 만든다. 투고타저는 반발 +0.010·항력 −0.005·그립 −0.005, 타고투저는 반대다. 각 지수의 범위는 0.800–1.300이며 공급 측정값도 이 범위를 넘어갈 수 없다. 질량·둘레는 유지한다. 검사·의결·다음 시즌 적용과 적용 후 두 시즌 관찰을 거치며 시즌 중 특성은 고정한다. 반발은 타구 초속, 항력은 비행, 그립은 투구 위치 분산에 실제로 작용한다. 특정 타율을 보장하는 보정은 없다.

선수는 지속되는 성향과 실제 부진·계약·회복·채무 부담을 비교해 훈련·휴식·사용·베팅·청탁 수락·거절·신고를 선택한다. 매일 위반 선수를 추첨하거나 무관한 양성·거래 증거를 만들지 않는다. 약물 사용은 기본 능력치를 덮어쓰지 않고 일시적인 경기력 효과와 누적 건강 부담을 준다. 실제 사용 기록과 검체의 추적 가능 기간이 있어야 양성 자료가 생긴다. 베팅은 관찰 이후 적립한 개인 자금과 한도 내 채무를 사용하고 정확한 예정 경기의 결과로 정산한다. 청탁은 베팅 접점과 실제 채무 뒤에 생기며 수락된 특정 정규시즌 경기에서만 고의적인 경기력 저하로 이어진다. 포스트시즌·국제대회·다른 경기 번호에는 퍼지지 않는다. 경기 전 신고는 고의적인 경기력 저하를 중단한다. 완료한 경기의 점수·기록을 다시 쓰지 않는다.

새 사건의 기본 출장정지는 금지약물 첫 위반 80경기·재위반 160경기·3회 이상 240경기, 불법 도박 60경기·소속 구단 베팅 120경기, 승부조작 청탁 수락 240경기다. 기존 사건은 당시 규정을 유지한다. 원본과 일치하는 조사 전 자진 신고·자료 제출·협조는 재심에서 25% 감경한다. 검체 불일치·입증 부족·인증된 치료 목적 승인은 처분을 취소한다. 사건 접수 때 행위 원본과 규정을 보관해 이적·은퇴·저장 복원 후에도 근거가 보존된다. 확정 다음 날부터 실제 완료한 구단 경기에 이행하며 취소·휴식일은 세지 않는다.

사회공헌은 선수 개인의 별도 적립금에서 실제 지급하고 영수증을 남긴다. 관찰 전 재산을 만들거나 구단 잔고·계약 연봉을 바꾸지 않는다. 3개월 이상 확인된 후원을 지급한 후보 중 지속 기간·연봉 대비 기여·후원처를 비교해 리그에서 시즌당 한 명에게 사회공헌상을 준다. 공개된 중대 사건 심의 중이거나 해당 시즌 중대 위반이 확정된 선수는 제외하며 기부로 징계를 줄이지 않는다. 사회공헌 포상은 경기 수상·명예의 전당 점수와 별도로 저장한다. 변하는 행동·후원 원장은 선수 live shard에 포함해 매일 선수 소개 전체를 다시 보내지 않는다.

프로필에서는 좁은 실전 경험 카드와 중복 출장정지 카드를 없애고 실제 집계된 1군·2군 타석·수비 이닝·교체 출전 표를 제공한다. 집계 시작 시점과 기타 리그 경험은 펼쳐 확인한다. 징계는 확정 여부·잔여 경기·처분·사유·적용 범위·이력을 구분한 카드로 표시한다. 비공개 행위 원장은 노출하지 않는다. 국가대표 대회 이력은 남색 머리글과 흰 카드, 금·은·동 결과색을 사용하며 준우승을 우승으로 잘못 집계하던 정규식도 수정했다.

중계 카운트가 켜지지 않던 원인은 컨트롤러의 `active`와 CSS의 `on` 클래스 불일치였다. 판정만 남은 과거 기록은 저장된 판정으로 카운트를 계산하고 원본을 바꾸지 않는다. 2스트라이크 파울·4볼·3스트라이크·사구·병살타를 구분한다. 세 번째 아웃은 다음 공수교대 때까지 남긴다. 도루 성공·실패를 별도 무투구 이벤트로 기록해 이닝을 끝내는 도루 실패도 빠지지 않는다. 기록을 남기는지에 따라 난수 순서나 경기 결과가 달라지지 않는다.

검증:

- 전체 Node 회귀 검사 110개 통과. 최종 행위 원본·신고 중단 수정은 관련 검사도 별도로 재실행했다.
- 실제 70경기·1,242개 공격 이닝·17,777개 투구에서 판정별 B/S와 투수 아웃·중계 아웃을 대조했다. 도루 성공 63건·실패 20건·이닝 종료 실패 8건을 포함했다.
- 실제 엔진의 중계 기록 유무를 30개 동일 난수 시드에서 비교해 경기 결과와 선수 기록이 일치했다.
- 실제 정규시즌 루프·일별 회복·사무국·연도 전환으로 두 시즌 1,440경기를 확인했다. 팀당 144경기, 이닝·선수 득점 합계, 시즌 집계, 사건 원본과 처분 이행 수가 일치했다. 아마추어·국제대회·이적 일별 처리는 이 시험에서 제외한다. 원자료: conduct-broadcast-v2.0.53-audit.json.
- Chromium 1080·390·320px에서 표시등의 실제 색, 카운트·주자·공수교대·징계 단계·기사·프로필을 검사했다. 기존 중계 자동 재생·배속·스크롤은 1920·1080·390·320px에서 확인했다.
- 클라우드 분리·압축·복원 후 전체 상태와 다음 실제 진행 결과를 대조했다. 행위·후원 원장도 손실 없이 복원되며 매일 player base를 다시 전송하지 않는다.

모든 검증은 격리된 합성 경기·저장을 사용한다. 실제 사용자 클라우드 저장이나 외부 금융 거래에 접근하지 않는다. 선수의 선택과 물성 변화는 경기 확률에 작용하며 특정 성적·승패를 보장하지 않는다.
