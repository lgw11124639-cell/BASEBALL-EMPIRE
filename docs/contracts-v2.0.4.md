# v2.0.4 계약 검증

기준 커밋: v2.0.3 `f0b9892`. 이 대화의 일반 연봉계약·FA 다년계약·외국인 계약 구분 요구와 저장소 변경 이력을 기준으로 수정했다.
별도 과거 채팅을 검색하는 기능은 제공되지 않았다.

## 계약 상태와 화면

`playerContractStatus`가 계약 상태를 일관되게 분류한다.

- 일반 국내 선수: 매년 연봉협상. 새 선수 프로필에 임의의 1~5년 계약기간을 만들지 않는다.
- FA 선수: 1년 FA도 FA 계약으로 표시한다. 보장기간 마지막 1년까지 일반 연봉협상에서 제외한다.
- 만료된 FA: 과거 계약금·연봉·총액은 이력으로 남기고 현재의 FA 보장계약과 구분한다.
- FA 미계약·방출·계약종료·입단 예정: 현재 상태와 직전/예정 연봉을 구분하며 자동 일반 연봉협상에 넣지 않는다.
- 외국인·아시아쿼터: 국내 FA와 분리한 1년 계약 및 계약 시즌을 표시한다. 국내 FA 인정기간/FA 계약 이력 UI를 대신 표시하지 않는다.

새 FA 계약에는 기존 `signedYear`, `years`, `annualSalary`, `signingBonus`, `totalValue`를 유지하면서 `startYear`, `endYear`를 추가한다.
기존 저장의 FA 계약은 기존 생성 경로대로 오프시즌 계약 연도 다음 시즌부터의 기간으로 해석한다.
현재 잔여 기간과 계약 종료 시즌을 함께 확인하여 과거 FA 이력에 일반 재계약의 `contractYears=1`이 붙어 현재 FA로 보이는 오류를 막는다.
트레이드로 소속팀이 바뀌어도 유효한 FA 계약은 보장한다.
오프시즌 정산 전에 이미 체결된 차기 시즌 계약은 시작 전에 1년을 소진하지 않는다.

FA 이력 없이 생성된 과거의 임의 `contractYears` 값은 다년 보장계약의 근거로 사용하지 않는다.
화면을 여는 것만으로 기존 필드나 계약 이력을 삭제/초기화하지 않으며, 연례 정산 때 일반 연봉계약으로 처리한다.

## 갱신과 지급

1. 일반 연봉협상은 국내 일반 계약 선수만 대상으로 한다. FA 미신청 잔류 시 이미 합의한 연봉을 같은 오프시즌에 다시 협상하지 않는다.
2. 미계약 FA를 다음 오프시즌에 원소속팀의 일반 계약으로 자동 복귀시키지 않는다.
3. 기존 미계약 FA 재협상 함수를 실제 오프시즌 진행에 연결했다. 포스트시즌 종료 후 계약 처리 기간의 14일 간격 검토를 유지한다.
4. 재협상에서 계약금을 먼저 결제하고 이적 보상금을 정산한다. 계약금 결제 실패 시 보상금과 성공 공시를 남기지 않는다. 보상금 정산 실패 시 계약금을 환불한다. 계약 성립 후에만 선수 이동·FA 행사·계약 이력을 확정한다.
5. 12월 5일 일반 외국인 재계약은 아시아쿼터를 처리하지 않는다. 아시아쿼터는 12월 6일 별도 절차에서 처리한다. 일반 외국인 투수 수에도 아시아쿼터를 합산하지 않는다.
6. 기존 프로필에 능력치 자료가 누락되어 보충하는 경우에도 FA 계약·계약 이력·기타 기존 프로필 필드를 덮어쓰지 않는다.

## 검증

Node.js 22.23.4에서 기존 테스트와 새 테스트를 합쳐 35개 진입점 통과.
실제 720경기 엔진 검증도 통과했고 v2.0.3의 타수·안타·장타·볼넷·삼진·사구·득점·아웃·자책점 집계와 모두 같았다.
리그 평균 목표를 맞추는 변경은 하지 않았다.

새 테스트:

- `player-contracts.test.cjs`: 실제 계약 상태/HTML 생성, 1년 FA, 만료 이력, 트레이드 후 계약 유지, 실제 오프시즌 FA 체결→마지막 보장연도→만료 후 일반 협상, 미계약 FA 유지, FA 미신청 연봉 중복 조정 방지, 차기 시즌 계약과 기존 프로필 보존.
- `fa-late-settlement.test.cjs`: 계약금 결제 실패, 보상금 수취 실패와 환불, 잘못된 성공 기록 방지, 실제 오프시즌 재협상 실행, 1년 FA 보장 및 반복 실행 시 지급/이력 중복 방지.
- `foreign-contracts.test.cjs`: 일반 외국인 처리에서 아시아쿼터 제외, 별도 재계약의 실행과 중복 방지, 일반 연봉협상 제외.

계약 로직 테스트는 계약과 관계없는 해외리그 생성·시즌 아카이브 등의 처리를 격리했다. 경기 검증은 실제 선수/투구/타구/스케줄 경로를 그대로 사용했다.
기존 FA 보상금 실패·하루 진행 롤백·은퇴·이적 이력 검사도 통과했다.

## 저장 호환성과 범위

클라우드 전송 코드와 저장 스키마 버전은 변경하지 않았다. 기존 시즌·통산·팀 이력과 FA 계약 총액을 보존하며 계약 날짜 필드만 새 계약에 추가한다.
실제 사용자 클라우드 저장에 접속하거나 수정하지 않았다. 이미 유실된 과거 계약 자료를 추측해 생성하지 않는다.
FA 자격 인정 시즌 수·보상 등급 계산식·계약 제안 금액 산식은 이번 수정 대상이 아니다.
