# v2.0.5 중계 스크롤 복구

데스크톱 중계 목록이 flex 레이아웃에서 70px까지 축소되고 전체 중계 화면이 스크롤되지 않는 현상을 실제 Chromium에서 재현했다.

- 전체 중계 화면은 세로로 스크롤한다. 닫기 헤더와 재생 버튼은 접근 가능한 위치에 유지한다.
- 중계 목록은 화면 높이에 따라 220~440px을 확보하고 내부에서도 이전 기록을 스크롤할 수 있다.
- 새 기록은 시간순으로 아래에 추가한다. 맨 아래에서 보고 있으면 새 투구·결과를 자동으로 따라간다.
- 이전 기록을 읽으려고 위로 올리면 위치를 유지한다. 다시 맨 아래로 내리면 따라가기가 재개된다.
- 기존 공수교대 시 현재 반이닝 목록 전환 및 원본 경기 중계 기록 보존 동작은 유지한다.
- 게임 결과·저장 데이터·계약 처리는 변경하지 않았다. v2.0.4의 계약 수정도 포함한다.

검증: `node tests/replay-scroll.browser.cjs`.
이 선택적 브라우저 검사는 Playwright와 Chromium이 필요하다. 현재 클라우드 환경에 있는 도구를 사용했으며 앱 의존성은 추가하지 않았다.
`CHROMIUM_PATH`로 Chromium 실행 파일을 지정할 수 있다. 테스트는 로컬 HTML/CSS/JS를 브라우저 요청에 제공하고 클라우드 로그인 부팅만 제외한다.
UI용 중계 fixture를 사용하며 실제 사용자 계정·클라우드 저장에 접근하지 않는다.

1920×1000 데스크톱 및 390×844 모바일에서 목록 높이·내부 스크롤·전체 화면 스크롤·수동/자동 중계 따라가기·과거 기록 읽기·하단 컨트롤 표시를 확인했다.
기존 70px 목록은 데스크톱 350px, 모바일 295px로 표시됐다.
HTML의 CSS 캐시 키와 앱/업데이터 버전도 갱신했다.
