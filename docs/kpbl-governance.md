## AI 인사와 독립 선수협회

총재 후보는 운영·선수 권익·경기 실무 경력과 정책 공약으로 소개한다. 구단은 가용 예산·급여 부담·부상 현황·유망주 비중으로 투표한다. 과반 후보가 없으면 상위 두 후보 결선을 진행한다. 총재는 정책 조정 경력과 경기 안전 경력을 근거로 사무총장·경기위원장을 임명한다. 후보 오버롤은 존재하거나 표시되지 않는다.

선수협회는 현역 1군·2군·육성·FA대기 회원의 직접투표로 구단 대표와 회장을 선출한다. 후보는 회원 선수이며 경력·같은 구단·포지션·처우 관심을 투표에 반영한다. 사무국의 후보 지명·임명 기능은 없다. 회원 명단·후보·실제 개별 투표를 선거별로 보존한다. 임기 중 대표의 이적·은퇴는 선거 당시 역사로 유지하며 다음 정기선거에서 현역 명단으로 갱신한다. 협의는 실제 미계약 FA 명단, 현재 부상 선수 명단, 정책 안건에 연결한다.

총재 3년, 이사회·총회 출석 정족수 2/3, 선출·정책 의결 출석 과반, 선수협회 2년, 동률 시 고정 ID 순은 **KPBL 가상 규정**이다. 실제 KBO 규약이라고 주장하지 않는다. 현재 게임의 총재 선거인은 10개 구단이며 이사회·총회는 같은 구단 대표로 구성한다.

## 정책과 신규 계약

필요성 검토 → 사무국 검토 → 구단 의견 → 선수협회 의견 → 수정안 → 이사회 의결 → 시행 공고. 각 단계는 서로 다른 게임 날짜에 진행하고 근거·구단별 찬반·선수협회 의견·표결을 저장한다. 부결도 보존한다. AI는 실제 최저연봉 부근 선수 수, 100경기 이상의 연장 이닝 부담, 시즌 박스스코어 타율을 근거로 안건을 만들며 같은 해 같은 종류 안건을 반복 생성하지 않는다.

시행은 다음 시즌부터다. 시즌 시작 시 공인구·연장·승부치기·최저연봉을 동결하고 기존 계약·과거 성적을 소급 수정하지 않는다. 최저연봉은 FA 제안과 최종 계약, 연봉 재협상, FA 미신청 재계약, 신인 계약, 육성 영입, 방출선수 재영입의 실제 계약 대상 시즌에 적용한다. 이미 보장된 FA 계약은 연봉 재협상에서 제외한다. 정책 시행 전에 서명한 신인 계약도 소급 변경하지 않는다.

구단주 화면은 조회 전용이다. 기존 `scheduleLeagueOfficeDecision`은 이전 저장·회귀 검증 호환을 위한 내부 함수로 남겨 두고, 수동 공고 UI는 제거했다. 새 AI는 의결을 거친 안건만 공고한다.

## 공인구

공급 업체·로트·질량·둘레·반발·항력·그립·검사 결과·재검사 원본 ID를 보존한다. 업체와 검사 기준·인증 표본 수치는 게임의 가상 자료다. 실패한 로트는 정책 적용을 보류하며 재검사는 원 불합격 로트를 연결한다. 통과한 공인구의 물리 특성을 다음 시즌 생성 시 복사하여 시즌 중 고정한다. 이전 시즌의 동결된 공인구 객체를 다시 생성하지 않는다.

반발·항력은 기존 `resolveBattedBall`의 타구 초속·비행 계산, 그립은 기존 `simulatePitchLocation`의 투구 위치 분산에 연결한다. 타율·홈런·ERA에 결과 보정 배율을 곱하지 않는다. 공인구는 국내 프로 1군·2군·포스트시즌에 적용하고 아마추어·국제대회는 기준구를 사용한다.

## 경기 사건·징계·이행

무작위 범죄·도핑·고의 사건은 생성하지 않는다. 현재 구현의 조사 대상은 **동일 경기 같은 투수의 실제 사구 3회 이상**이다. 엔진이 기록한 투수 ID·타자 ID·이닝·투구열·결과를 확보한다. 이것은 KPBL 가상 안전 규정이며 고의성이나 범죄를 판단하지 않는다. 근거가 없는 일반 사구나 투수 식별 불가 사건은 생성하지 않는다.

조사 → 소명 자료 열람 및 선수협회 검토 → 경기위원회 심의 → 결정 → 재심 기록 대조 → 확정 → 이행·복귀. AI는 실제 사건 자료로 소명·재심을 검토하며 사람이 실제로 발언했다는 가짜 인용을 만들지 않는다. 실제 3회 이상 확인 시 가상 안전 규정의 1경기 정지를 확정하고 입증 부족 시 취소한다. 확정 전에는 출전 제한을 적용하지 않는다.

감독의 선발·벤치·투수 역할·대체 선수 풀에서 해당 범위의 확정 출장정지 선수를 제외한다. 프로필과 공통 뉴스에 사건·잔여 경기·복귀를 연결한다. 경기 시작 시 등록 구단과 1군/2군 등록 상태를 캡처하고 확정일 이후 해당 구단의 실제 완료 경기만 산입한다. 휴식일·취소·과거 2군 재생성은 산입하지 않는다. 시즌·범위·날짜·구단·명시적 경기 ID/더블헤더 번호로 중복 이행을 방지한다. 정규시즌·2군·포스트시즌·국제대회는 별개 범위다. 정규시즌 정지는 포스트시즌에 적용·차감하지 않으며 잔여 정지는 다음 해당 범위 시즌으로 이월한다. 말소·2군 이동 중에는 1군 정지를 차감하지 않는다.

## 포스트시즌과 기록 그래프

정규시즌의 연장 한도·승부치기를 포스트시즌에 전달하지 않는다. 포스트시즌은 가상 별도 규정으로 15회, 승부치기 없음, 동점 재경기다. 동점이면 시리즈 승수를 올리지 않으며 임의 추가 득점을 만들지 않는다. 기존 정규시즌과 포스트시즌 기록 분리는 유지한다.

타격 환경은 현재 시즌 정규시즌 박스스코어만 합산한다. 시즌 보관 시 `leagueEnvironment`를 함께 저장하고 연도별 타율·ERA 그래프와 표에 사용한다. 은퇴 선수 누적 기록을 현재 시즌에 더하지 않는다. 일부 박스스코어나 지표가 없으면 해당 지표는 `null`/`—`이며 그래프 선도 끊는다. 기존 보관 시즌에 환경 집계가 없다면 임의로 복원하지 않는다.
