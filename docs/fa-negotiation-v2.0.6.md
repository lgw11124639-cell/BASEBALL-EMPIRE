# v2.0.6 FA 쌍방 협상

기존 `2 + 무작위 0~2년`, `기존 연봉에 일괄 인상` 경로를 제거했다.
FA 신청, 구단 제안, 선수의 조건 판단, 계약 정산을 분리한다. 이미 체결된 계약의 기간·연봉·총액과 저장된 시즌/통산 이력은 소급 변경하지 않는다.

## 구단 판단

- 최근 최대 3시즌의 실제 출전·성적을 최근 시즌에 더 큰 가중치로 사용한다. 타자는 출루율·장타율과 출전량, 투수는 역할별 이닝과 실점 억제를 평가한다. 소표본은 관측된 리그 기록에 완화하며, 자료가 없으면 스카우팅 판단과 짧은 보장기간을 사용한다.
- 시장의 다른 국내 선수 연봉 중앙값을 참고한다. 해당 선수의 기존 고액 연봉에 무조건 일정 비율을 더해 제안하지 않는다.
- 나이에 따른 향후 기여도 변화, 최근 부상 기록과 현재 회복 상태, 관측 신뢰도를 바탕으로 향후 시즌을 전망한다. 전성기 선수와 40세 선수에게 같은 방식으로 임의의 4년 계약을 주지 않는다.
- 평가 기간 안에서 서로 다른 계약기간 제안을 비교한다. 내부 전망 기간은 5시즌이며, 이를 KBO의 법적 계약기간 상한으로 주장하는 것은 아니다.
- 포지션 경쟁, 예상 출전 역할, 예산·미지급 운영비·기존 인건비·계약금·보상금·보장 연봉 부담을 확인한다. 계약 연봉을 미리 이중 차감하지 않고 지급 여력을 남겨 둔다.
- 전 구단에 불리한 제안이면 제안 자체가 없을 수 있다. 선수가 수락해도 실제 정산이 실패하면 선수 이동이나 FA 행사 횟수를 확정하지 않는다.

## 선수 판단

선수별 금액·보장기간·출전 기회·우승 경쟁력·원소속팀 선호를 따로 평가한다. 기본 성향은 선수 ID로 안정적으로 생성하므로 재접속이나 같은 날 재실행으로 매번 다른 결정을 추첨하지 않는다.

선수는 낮은 연봉/총액, 짧은 보장기간, 부족한 출전 기회를 거절하거나 다른 구단 제안을 기다릴 수 있다. 동일 금액이라도 우승 경쟁력이나 잔류 선호 때문에 선택이 달라질 수 있다. 고령 선수도 구단이 주려는 기간보다 긴 보장을 요구하며 거절할 수 있다.

기다리는 기간에 따라 요구 조건과 구단 제안을 다시 검토하지만, 특정 라운드에서 무조건 수락하게 하거나 시장의 계약 성사율을 정해 놓지 않는다. 전년도 미계약 FA도 다음 시즌에 계속 협상할 수 있다. 시즌 중 체결한 계약은 해당 시즌부터 시작한다.

FA 시장과 선수의 FA 상태 설명에 `선수 제안 거절`, `구단 제안 없음`, 실제 거절 이유를 표시한다. 내부 능력치나 협상 점수는 UI에 노출하지 않는다.

## 기록·정산

- 거절/대기 중에는 계약금·보상금 지급, FA 행사 횟수 증가, 원소속팀 자동 재계약을 하지 않는다. 미계약 선수의 직전 연봉을 다음 해에도 계속 청구하지 않는다. 새 협상에서는 기존 계약 연도의 급여 의무를 원소속팀에 남기고 새 계약은 실제 시작 시즌부터 지급한다. 종전 연봉 자료가 없는 과거 계약은 금액을 추측해 미지급금으로 만들지 않고 저장된 급여 처리를 유지한다.
- 선수와 구단의 합의 후 기존 계약금/보상금 지급·환불 경로로 정산한다. 확정된 새 계약만 계약 이력에 추가한다.
- 기존 계약 이력과 소속팀 이력을 유지한다. 1군 출전 역할을 예상하더라도 등록 인원 28명을 넘겨 자동 등록하지 않는다.
- 같은 선수의 같은 날짜 협상은 한 번만 처리한다. 구단별 대표 제안과 이유를 라운드별로 남겨 모든 기간 조합을 저장하는 불필요한 데이터 증가를 줄인다.
- FA 보상 등급이나 직전 연봉 자료가 불완전하면 타 구단의 보상금을 임의로 0으로 간주하지 않는다.

## 검증 결과

합성 성적과 통제된 재정으로 실제 앱 함수를 실행했다. 실제 KBO 관측 자료를 재현하거나 모든 사용자 저장의 결과를 예측하는 시험은 아니다.

동일 성적·시장 조건에서 **구단 제안** 비교:

| 나이 | 제안 기간 | 연봉 | 계약 총액 |
| --- | ---: | ---: | ---: |
| 28 | 5년 | 7.81억 | 46.86억 |
| 33 | 5년 | 6.40억 | 38.40억 |
| 37 | 2년 | 6.15억 | 14.76억 |
| 40 | 1년 | 5.26억 | 6.31억 |

이 표는 제안이며 자동 체결 결과가 아니다. 기존 연봉이 20억인 40세 선수는 더 높은 조건을 요구하며 제안을 거절하고 기다리는 경로를 검증했다. 다른 조건의 40세 선수가 후속 협상에서 실제 수락하는 경로도 검증했다.

10개 구단·후보 20명(전성기/고령, 동일한 좋은 성적, 서로 다른 직전 연봉)의 시나리오에서 10명 계약, 10명 미계약, 선수의 제안 거절 라운드 53회가 발생했다. 이 수치는 모델의 목표나 강제 비율이 아니다. 계약금은 한 번만 지급됐고 구단 간 보상금 이전은 전체 예산 합을 보존했다. 거절자의 FA 행사 횟수와 과거 기록도 유지됐다.

Node.js 22.23.4에서 기존 검사와 새 검사를 합쳐 37개 테스트 진입점, 실제 720경기 검증을 수행했다. 경기 집계는 기존 버전과 동일하며 리그 평균을 맞추는 변경은 하지 않았다.

새 검사:

- `fa-negotiation.test.cjs`: 나이/성적/부상/소표본에 따른 제안, 기존 연봉 자동 인상 제거, 금액·기간·출전·우승·잔류 선호별 거절, 대기·재협상, 같은 날 중복 방지, 화면의 거절 이유, 기존 보장계약 보존, 다음 시즌 계약 체결.
- `fa-market-simulation.test.cjs`: 10개 구단의 실제 협상 흐름, 계약/미계약 공존, 선수 거절, 계약금과 보상금 보존, 1군 등록 한도, 이력 보존.

기존 계약 수명주기 검사는 실제 시장의 동료 연봉과 수락 성향을 명시해 보장기간 검증을 유지했다. 기존 지급 실패 검사는 합의가 끝난 상황을 격리하여 계약금 실패·보상금 환불·중복 지급 방지를 계속 검증한다. 선수의 수락/거절 자체는 위 새 검사에서 실제 판단 함수를 사용한다.

## 범위

실제 야구 계약의 모든 에이전트 전략·세금·옵션·트레이드 거부권을 구현한 것은 아니다. 전망과 선호는 설명 가능한 단순화 모형이다. 일반 연봉협상·외국인 재계약의 기존 별도 절차와 클라우드 저장 스키마/전송 코드는 유지한다. 사용자 클라우드 저장에 직접 접속하거나 이미 체결된 계약을 재산정하지 않았다.
