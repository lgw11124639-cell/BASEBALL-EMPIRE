# v2.0.3 장타·사구 검증

기준: v2.0.2 `107054f`. 기존 저장을 초기화하거나 클라우드 전송 코드를 변경하지 않았다.
선수 능력치 UI, 계약 데이터와 기존 경기 기록도 유지한다.

## 장타

99/103mph 문턱과 2루타보다 먼저 실행되던 독립적인 3루타 추첨을 제거했다.
이미 안타로 판정된 비홈런 타구에서 깊이·외야수 사이의 방향·타구 속도·주력·수비 범위·송구 능력에 따라
연속적인 추가 진루 확률을 계산한다. 3루타는 2루타 진루가 가능한 타구의 추가 진루로 판정하며 깊이·주력 조건도 필요하다.
따라서 약한 타구가 속도 경계 때문에 갑자기 2루타가 되거나, 2루타로 판정될 수 없는 타구가 독립 추첨만으로 3루타가 되던 경로를 없앴다.
홈런과 안타 여부 판정은 이번 수정에서 유지했다.
이 모델은 타구별 확률 모델이며 공기저항·수비 이동·송구를 시간별로 적분하는 완전한 물리 모델은 아니다.
리그 누적 타율·ERA를 입력받거나 목표 평균에 맞춰 결과를 사후 조정하지 않는다.

## 사구

실제 투구 루프에 사구 종결 결과가 없던 문제를 수정했다.
투구 위치와 좌/우 타석의 몸 영역을 확인하고, 구속·타자의 인지에 따른 회피 확률을 거쳐 접촉 여부를 판정한다.
몸쪽 영역을 지나는 모든 공이 몸에 맞았다고 간주하지 않는다.
몸에 맞은 공은 즉시 데드볼로 처리하여 폭투/포일과 주자 추가 진루를 함께 발생시키지 않는다.
스윙한 공은 사구 출루로 처리하지 않으며 스트라이크로 기록한다.
사구는 타석·투수 상대 타자 수에 포함하지만 타수·볼넷에는 넣지 않는다. 만루 사구는 밀어내기 1득점이다.
몸 좌표와 회피 확률은 단순화된 모델이다. 의도적으로 공에 맞거나 회피를 거부하는 선수 행동은 별도로 시뮬레이션하지 않는다.

## 실제 엔진 결과

Node.js 22.23.4. 같은 초기 선수단에 경기 난수만 다른 720경기 시즌 2회, 총 1,440경기.
각 시즌 팀당 144경기, 이닝 점수 합·개인 득점 합·투타 기록 대조 통과.

| ERA | 3.2063 | 3.9085 | 3.6883 |

| 팀 경기당 득점 | 3.3854 | 4.0708 | 3.8229 |

홈런 판정식을 바꾸지 않았어도 추가 진루와 사구에 따른 타석 수·난수 소비·투수 교체·후속 경기 선수 상태가 달라져 홈런 수는 달라질 수 있다.
기본 seed에서 10득점 이상은 102/1,440 팀 경기, 최대 22득점이다. 전체 득점 분포는 결과 JSON에 있다.
이는 트레이드·성장·2군·국제대회 동시 진행·클라우드 저장을 제외한 초기 선수단의 1군 검증이다.
타율 .260은 아직 확인되지 않았다. 다른 초기 선수단 및 장기 시즌의 보편적 밸런스가 해결됐다는 뜻도 아니다.
실행 약 25초는 이 환경의 엔진 테스트 시간이며 브라우저나 저장 성능 향상을 의미하지 않는다.

## 재현과 회귀 검사

```sh
node tests/extra-base-hit.test.cjs
node tests/hit-by-pitch.test.cjs
BALANCE_REPORT=/tmp/balance.json node tests/league-balance.test.cjs
BALANCE_SEED=42 BALANCE_REPORT=/tmp/balance42.json node tests/league-balance.test.cjs
```

장타 검사는 99mph 미만 갭 타구, 강한 얕은 타구, 깊이에 따른 3루타 제한, 주력·수비·송구의 단조성을 검증한다.
사구 검사는 좌/우 타석과 회피·구속 상호작용, 실제 투구 루프의 만루 밀어내기·타수/볼넷 제외·스윙 삼진·데드볼을 검증한다.
회피를 항상 실패시키는 결정적 시나리오는 경기 처리 규칙만 검증하기 위한 fixture이며 시즌 검증에서는 실제 회피 함수를 그대로 실행한다.
중계 기록 유무에 따른 동일 결과 검사와 기존 국가대표·2군·기록·계약 회귀 검사도 유지했다.

다음은 타구 종류별 아웃·안타 분포와 투수/타자 능력 상호작용의 추가 검증이다. 타율을 목표값에 강제로 맞추지 않는다.
