# v2.3.47 중계 투구 동작

실제 경기 중계에 클럽 10종과 국가대표 28종 유니폼, 네 투구폼의 연속 이미지 동작을 적용했다. 기존 유니폼 원본은 변경하지 않고 양방향 모션 필드로 120 표시 상태를 만든다. 보라색 유니폼의 오버핸드는 승인된 투명 배경 60컷 원본을 사용한다. 다른 조합은 기존 10개 구분동작을 보간한다. 120개의 독립 생성 이미지라는 의미는 아니다.

다리 비율을 늘리고 축발과 착지점을 등록해 동작 전환의 위치 흔들림을 줄였다. 원거리 타자와 포수 배치, 타자 방향, 비행 중 공의 축소, 접을 수 있는 존 확대를 적용했다. 기록된 투구 종점과 판정은 유지한다.

검증: 게임 로직 160개 회귀 검사, Chromium/WebKit 중계 방향 및 국가대표 유니폼 검사, 38종 유니폼 × 네 투구폼 렌더링 검사.
