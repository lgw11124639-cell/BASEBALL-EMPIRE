# 단일 시즌 최고 기록

1군 정규시즌 최다 안타·홈런·탈삼진과 실제 투구 최고 구속을 역사 → 시즌 기록에 표시한다. 이전 시즌 스냅샷과 보존된 통산 시즌 자료, 현재 공식 박스스코어를 초기 기준으로 삼는다. 투구 자료가 없는 과거 구속은 능력치로 추정하지 않는다.

경기 종료 후 기존 최고치를 초과한 경우 대기록 기사를 발행한다. 동률은 신기록으로 처리하지 않으며 같은 선수·부문·시즌의 추가 경신은 기록만 갱신하여 반복 기사를 막는다. 기사는 발행 당시 신기록과 종전 기록을 보존한다. 업데이트 이전에 이미 달성한 기록은 초기 기준으로 등록하고 기사를 소급 발행하지 않는다. 포스트시즌·국제대회·2군 성적은 합산하지 않는다.

기록과 발행 중복 방지 키는 history.singleSeasonRecords에 보관하여 시즌 전환과 저장 후에도 유지한다. 진행 중 시즌 기록임을 표시한다. 기존 사이클링히트·노히트노런 기사와 공통 경기 종료 경로를 사용한다.

검증: tests/single-season-records.test.cjs 및 전체 회귀 검사.
