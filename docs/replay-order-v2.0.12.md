# v2.0.12 문자중계 최신순

공통 문자중계 출력 함수에서 새 항목을 목록 맨 앞에 삽입하도록 변경했다. 최신 투구·타석 결과·선수 교체·이닝 안내가 위에 표시된다. 기존 경기 이벤트 배열과 저장 기록의 시간 순서는 변경하지 않는다. 공통 화면을 사용하는 프로·2군·국가대표·포스트시즌 다시보기에 적용된다.

목록 맨 위에서는 새 항목을 계속 따라간다. 아래로 내려 이전 기록을 읽고 있으면 삽입된 높이만큼 scrollTop을 보정해 읽던 내용을 유지한다. 기존 현재 반이닝 표시와 재생 제어는 유지한다.

Playwright/Chromium 1920px·390px에서 첫 항목이 최신이고 마지막 항목이 가장 오래된 내용인지, 자동중계 상단 추적, 이전 기록 읽기 위치 보존, 화면 전체 스크롤과 고정 컨트롤을 확인했다. 문법/릴리스, 국가대표 기록 격리, 중계 유무 경기 엔진 일관성 검사도 수행했다.
