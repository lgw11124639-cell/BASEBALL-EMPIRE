# v2.0.11 유망주 화면

리그의 고교/대학/독립 최상위 탭을 유망주 탭 하나로 대체했다. 해당 리그의 생성·시뮬레이션·드래프트·저장 로직과 기존 데이터는 유지한다. 이전 pane 값도 유망주 화면으로 연결한다.

유망주 안에는 프로/아마추어 하위 탭이 있으며 각각 최대 10명만 표시한다. 아마추어는 현재 시즌 고교·대학·독립 미계약 선수를 통합하고 프로는 25세 이하 국내 등록 선수 중 1군 통산 300타석/60이닝 이하 선수를 대상으로 한다. 은퇴/외국인/합류 전/미계약 프로는 제외한다. 통산 출전은 이전 시즌 스냅샷과 careerRecords를 연도별로 중복 없이 합산한다. 자료가 10명 미만이면 실제 인원만 표시한다.

순위는 저장된 현재 기량, 성장 여력과 출전 경험을 종합한다. 순위 번호와 실제 경기 기록만 표시하고 능력치/오버롤/평가 점수는 노출하지 않는다. 이름을 누르면 기존 프로/아마추어 상세창을 연다. 프로 2군 시즌 기록만 있는 경우 2군 기록을 명시한다. 화면을 보는 동작은 선수를 생성하거나 훈련시키거나 저장 데이터를 변경하지 않는다.

검증: TOP 10 제한, 프로 자격/과거 주전 제외, 아마추어 리그별 같은 숫자 ID 구분, 기존 최상위 탭 제거, 빈 목록, 조회 불변성, 릴리스 검사. Playwright/Chromium으로 1920px/390px에서 탭 전환, 아마추어 상세 기록 연결, 가로 넘침 없음을 확인했다. 외부 서비스/실제 클라우드 계정 저장은 사용하지 않았다.
