# v2.0.19 운영진·선수 인사와 경기 마무리

기준: main e3bb66d. 사용자 요청 범위는 운영진 계약/나이/감독 경질·자진사퇴, 장기 미출전 선수의 방출·은퇴, FA 계약과 보상 기사 순서, 완투·완봉 경로다. 기존 서버 DB와 사용자 저장은 읽거나 수정하지 않았다.

## 실제 원인과 변경

- 지도자 재계약 기사가 최초 부임 연도(hiredYear)를 시작으로 표시해 2027~2041년처럼 보였다. 재임 시작과 개별 계약 시작을 분리하고 계약별 이력을 남긴다. 사장·단장·감독은 3년, 2군 감독은 2년, 기타 코치·지원 인력은 1년으로 신규 계약한다. 시즌 종료 재계약은 다음 시즌부터다. 기존 계약 종료 연도와 부임 기록은 유지하며, 누락된 시작 연도는 기존 계약 규칙으로 복원한다. 오래된 재계약 기사도 원문을 바꾸지 않고 표시만 바로잡는다.
- 운영진 생년과 나이를 보존한다. 기존 운영진은 부임 시점과 인물에 따른 고정 기준으로 생년을 보완하며, 은퇴 선수 출신은 실제 선수 나이와 은퇴 연도를 사용한다. 연도 변화가 한 번만 나이에 반영된다. 고령자의 은퇴와 대체 선임을 연결하고 은퇴 지도자를 선수 출신 후보로 다시 뽑지 않는다.
- 감독 인사는 전력 기대, 전체/최근 성적, 부상 공백과 재임 기간으로 평가한다. 성적 부진에 대한 자진사퇴와 구단 경질을 구분해 후임, 계약, 기사, 시장, 인사 이력에 기록한다. 동일일 중복 심사와 새 감독의 즉시 연속 교체를 막는다. 사장·단장 후보를 현장 감독으로 잘못 선임하지 않는다.
- 기존 방출은 낮은 능력 평가에 나이/낮은 확률을 곱한 조건에 치우쳐 장기간 출전하지 못하는 선수가 남을 수 있었다. 최근 1·2군 활동, 포지션 경쟁과 차기 시즌 계획을 함께 검토한다. 젊은 육성 선수, 재활자, 최근 영입자, 보장 계약과 실제 2군 활동은 보호한다. 현재 비시즌 정산을 마친 기존 세이브도 다음 비시즌 하루 진행에서 새 심사를 한 번 수행한다.
- 미계약 선수의 연말 은퇴 함수가 정규시즌 진행에서만 호출돼 실제 비시즌 12월 31일에는 작동하지 않았다. 비시즌에 연결하고, 실제 2군 활동·장기 비활동을 은퇴 판단에 반영한다. 과거 기록을 삭제하거나 소급 은퇴시키지 않는다. 은퇴 기사에는 마지막 확인된 1군 시즌/구단과 해당 시즌 2군 활동을 구분하고 은퇴 시제에 맞춰 쓴다.
- FA 보상금 결제 함수가 계약 확정 전 보상 기사를 발행했다. 결제 실패 시 복구는 유지하고 계약 확정 → 보상 완료 → 특집 순서로 발행한다. 같은 날의 기존 기사도 동일 선수 거래 내에서 이 순서로 표시한다. 계약 재정산 중복을 차단한다.
- 선발 선택에 inning<=8 조건이 있어 9회에 강제 교체됐다. 낮은 투구 수와 피로, 적은 출루·실점, 감독 성향과 점수 차를 바탕으로 마무리 기회를 판단한다. 9회 진입을 무조건 허용하지 않으며 투구 부담, 위기, 국제대회 제한은 계속 적용한다. 완투/완봉 기록은 실제 전체 수비 아웃과 무실점 여부로만 집계한다.

## 검증 범위

전체 테스트 55개: 신규 staff-lifecycle, roster-inactivity, fa-news-flow, complete-game-path와 기존 전체 회귀를 실행한다. 운영진은 외부 야구/아카이브 엔진을 격리한 실제 시즌 전환 컨트롤러로 30년을 검사한다. 완투 경로는 실제 타석·이닝 엔진과 별도의 실제 720경기 검사로 확인한다. 장기 테스트가 전체 게임의 30년 완전 통합 실행을 의미하지는 않는다.

분리된 타석 테스트에는 새 실제 선발 투구 수 함수를 추가로 로드했다. 기존 검증 조건은 유지했다. 클라우드 왕복 비교에서 간헐적으로 달라진 것은 대학 선수의 Math.random 부상 추첨이었다. 실제 차이 경로를 확인한 뒤 같은 다음 날을 비교하는 두 실행에 동일한 난수열을 제공했다. 복원 상태 전체 동일성 검증은 유지했다.

실제 사용자 저장을 대상으로 한 브라우저 검사는 수행하지 않았다. 신규 판단은 이후 게임 진행에 적용되며 이미 지나간 방출·은퇴 결과를 다시 쓰지 않는다.
