# 2.0.56 도박 반복·재범 처분·징계 이행 수정

도박이 과하게 발생한 주원인은 위험 선호에 무조건 더하던 선택 가중치와 `borrow_and_gamble`의 반복 제한 오류였다. 현금으로 베팅할 수 있으면 `borrow` 기록이 생기지 않아, 과거 한 번의 패배로 이후 매월 같은 선택이 다시 열렸다. 심의·출장정지 중의 재베팅도 막지 못했다. 사건 한 건에 조사부터 확정까지 기사 여섯 건을 발행해 노출량도 증폭됐다.

무조건 가중치를 없애고 실제 관찰한 25% 이상 소득 감소와 새 경기 부진·회복 부담이 함께 있어야 초기 베팅을 고려하도록 한다. 소득을 처음 관찰하는 기존 저장은 현재 연봉을 기준으로 시작한다. 과거 소득을 만들어내지 않는다. 실제 소득 감소는 최대 180일 관찰하며, 연봉이 회복되면 감소 폭도 바로 줄어든다. 합법적인 훈련·휴식과 경력 손실을 함께 비교하므로 이런 조건이 곧 베팅을 뜻하지 않는다.

손실 만회 선택은 실제 정산된 최근 60일 내 패배에 연결하고 패배 후 3일이 지나야 한 번 재검토한다. 월별 판단 사이에도 실제 결과에 반응할 수 있어, 발견 전 베팅→채무→청탁의 인과 경로는 유지한다. 자동 신용 베팅은 실제 자금 부족과 365일 제한을 검사하고, 연결된 손실은 차입 기록 유무와 관계없이 한 번 사용한 것으로 남긴다. 연도가 바뀌어도 제한은 초기화되지 않는다. 공개된 중대 사건 심의·확정 처분·자진 신고·적발 이후의 억제 기간에는 자동 베팅을 막는다. 정규시즌 청탁의 자동 수락은 실제 출전 가능성이 있는 건강한 1군 선수에 한한다.

기사 발행은 조사 개시와 최종 결정으로 줄이고 복귀 소식은 실제 이행 후 남긴다. 사건의 조사·소명·심의·결정·재심·확정 과정은 사무국 운영 이력과 선수 기록에 모두 남는다. 이미 발행된 기사나 저장된 사실을 삭제·수정하지 않는다.

새로 접수하는 사건의 v3 기준:

| 유형 | 첫 위반 | 재범 | 3회 이상 |
| --- | --- | --- | --- |
| 벤치 충돌 | 3경기 | 6경기 | 12경기 이후 최대 24경기 |
| 금지약물 | 80경기 | 160경기 | 영구제명 |
| 불법 도박 | 60경기 | 180경기 | 영구제명 |
| 소속 구단 경기 베팅 | 120경기 | 영구제명 | 영구제명 |
| 승부조작 청탁 수락 | 영구제명 | 영구제명 | 영구제명 |

입증 부족·인증된 치료 목적 승인은 처분을 취소한다. 최초 청탁 수락 사건에서 경기 전 자진 신고와 실제 철회가 원본으로 확인되면 재심으로 제명안을 240경기로 바꿀 수 있다. 반복 중대 위반에 대한 제명은 단순 협조만으로 자동 감경하지 않는다. 과거 v1·v2 사건의 확정 처분과 기록은 당시 기준을 유지한다. 제명은 최종 확정 다음 날부터 해당 대회 범위에서 출전을 차단하며 선수를 삭제하거나 은퇴 처리하지 않는다.

여러 출장정지는 가장 먼저 확정된 처분부터 하나씩 이행한다. 실제 완료 경기 한 번에 한 선수의 처분 한 건만 차감한다. 예를 들어 2경기와 3경기는 총 5경기다. 1군·2군 이동으로 같은 날 다른 대회에서 중복 차감하지 않는다. 같은 대회의 실제 더블헤더는 서로 다른 경기로 센다. 취소·예정·미완료 경기는 산입하지 않는다. 기존에 저장된 잔여 경기·이행 기록은 보존하고 이후 이행에 이 원칙을 적용한다. 한 처분을 끝내도 다른 처분이 남으면 복귀 보류로 표시한다.

검증은 격리된 합성 저장·실제 엔진으로 수행한다. 동일한 700명에 소득·성적 변화가 없는 5년 사무국/일정 정산 시험에서 자동 베팅은 기존 4·36·36·36·36건에서 0·0·0·0·0건으로 바뀌었다. 이는 실제 리그 연간 발생률 예측이 아니라 이유 없는 반복의 재현 시험이다. 실제 소득 급감과 부진이 있는 선수의 선택, 패배→채무→청탁 경로도 별도 검사로 유지했다. 재범 단계·제명 확정 시점·치료 목적 취소·순차 이행·저장 복원·기사 사실 동결·PC/모바일 표시를 검증한다.
