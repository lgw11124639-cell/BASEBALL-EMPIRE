# v2.0.9 하루 진행 복사 비용

사용자 화면: 2035-01-10 하루 진행 3.5초, 백업 0.8초, 저장 2.7초, 통신 0.8초, 전송 33KB. 전송량 감소만으로 대기 시간이 해소되지 않았다.

- 복구 백업은 모든 변경 가능한 객체/배열을 독립 복사하되 불변 원시 문자열을 재사용한다. 순환/공유 참조, undefined, NaN, 희소 배열을 보존한다. 비표준 컨테이너는 전체 native structuredClone으로 처리한다. 기존 gameResults 기록의 컨테이너 복사 방식은 유지한다.
- 저장 성공 후 acknowledged wire snapshot은 gzip/base64 문자열을 공유하고 변경 가능한 객체 필드만 함께 structuredClone한다. 실패/충돌 시 기준점을 갱신하지 않는다. 매일 저장 및 서버 revision 검증은 유지한다.
- 자동 진행 기본 추가 대기를 1초에서 0.3초로 변경하고, 저장 완료 후 즉시 다음 날을 시작하는 '최대한 빠르게'(0ms)를 추가한다. 동시에 여러 날짜를 실행하거나 저장을 생략하지 않는다.

대표 합성 장기 기록 30,000개를 같은 상태로 복사하여 원본/결과를 비교했다. 로컬 Node의 7회 중앙값: native 34.75ms, 변경 15.72ms. 실제 사용자 자료/기기 전체 하루 시간의 측정 결과는 아니다. 데이터 구조/기기별 개선 폭은 다르며 통신 지연은 그대로 남는다.

검증: 복사 동일성/독립성/순환/공유/희소 배열/특수 자료형, 하루 진행 실패 복구, 저장 실패/재시도/응답 유실/충돌 회귀. 사용자 계정 저장 데이터에 접근하지 않았다.
