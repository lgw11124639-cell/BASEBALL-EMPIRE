# Club swing images

Four complete poses in a 2 × 2 atlas, with each club's ready-batter image as the authoritative clothing reference. Clothing is baked into every pose; runtime does not tint a different uniform over it. The manifest records ready-batter and generation-source hashes. Handedness reflects the entire actor.

Regenerate with scripts/prepare-batter-uniforms.mjs, BE_POSE_PACKER and (for bunt) BE_BUNT_MASTER. A bunt presents the bat, meets an attempted pitch, then recovers. A taken ball keeps the presentation pose and recovers without a contact pose. Animation never changes the recorded plan or outcome.
