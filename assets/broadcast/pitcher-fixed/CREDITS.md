# Fixed-proportion pitcher review model

This is a separate review page, not the current game actor.

Anatomical mesh, default rig and weights, and Asian/young/male macro targets:
MakeHuman Community, CC0-1.0. See ../pitcher3d/LICENSE.CC0.txt.
Official upstream: https://github.com/makehumancommunity/makehuman

Face and cloth colour reference: generated fictional Korean adult male,
material-reference.png. This reference provides colour only. It does not mask
or remove the mesh background and it does not supply independently swapped limbs.

One fixed 1.88m anatomical body and one skeleton are posed 120 times per delivery.
Four deliveries: overhand, three-quarter, sidearm, submarine.
The model is rendered with native transparent WebGL output. No raster matting.
Uniform colours use the existing shared ten club and 28 national specifications.
This is a new 3D interpretation of the reference, not an identical photographic cut.
